本次新增／修改关键事实定向复核至 2026-09-07；未重核的稳定旧题保留真实原核验日期，不统一刷新日期伪装新审核。
完整覆盖状态和社区线索映射在 data/coverage.json，应用“来源与内容边界”可见。复杂组合牌／标线实景、其他城市钉胎费、隧道新增支付机细节仍明确标注未完成核验，不编答案。

来源 181 项，材料类型、原始快照／证据记录分别显示。来源档案实际字节 SHA-256 索引位于 data/evidence-index.json；与 URL 指纹区分。不同语言 URL 不代表两份独立证据。单一直接权威原始文件的题显式声明 primary-original 策略，不用无关第二链接凑双源。供应商合同实例不是全国法规。

## 开发和验证

Node.js 22.13+（CI 使用 22），npm ci。

- npm run dev：Sites 本地开发。
- npm run test:pages：内容校验、lint、类型、学习／会话／离线单元测试、实际 Pages 构建与完整资源哈希测试。
- npm run test:research：本地完整研究档案与原图字节校验。源码 ZIP 内包含这些目录。
- npm run test:sites：备用 Sites 构建及 SSR 测试；不执行 Sites 发布。
- npm run build:pages：输出 pages-dist，固定 base /nordic-road-ready/。
- npx vite preview --config vite.pages.config.ts --host 127.0.0.1 --port 4173：本地发布构建预览。
- npm run package:project / npm run package:research：更新交付 ZIP 和 SHA-256。

CI 校验网站内图片与完整证据索引；原始研究文件不在公共仓库时，使用已核对的原图哈希记录，不声称 CI 再次读取了私人原图。

## 离线

构建自动生成 offline-manifest.json，包含首页、JS、CSS、题库（打包在脚本）、图标和本地素材的路径／大小／SHA-256。
“下载完整离线包”按清单校验后才切换完整包指针；失败保留旧包，重试可复用已校验资源。缓存名前缀包含本站 scope，不枚举删除其他应用缓存。
单包预算 100 MiB，成功切换后保留当前及上一完整版本。准备更新时可能临时占用第三份包空间；浏览器仍可能因配额拒绝下载。
导航只从完整包读取或请求网络，不将错误响应覆盖离线首页。手动“检查离线就绪”重新核对实际缓存而非只读下载日期。

手机准备：普通浏览器打开主站 → 添加到主屏幕 → 下载完整包 → 检查就绪 → 飞行模式 → 彻底关掉并重开，完成一次看图、答题和进度恢复。出发前导出 JSON。
浏览器存储驱逐、无痕模式、实际手机厂商限制不能由网页保证；持久化请求不是免清除保证。
