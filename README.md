# 北境自驾课

面向中国游客的挪威与冰岛自驾交规学习 PWA。题目答案以两国现行官方法规、交通主管部门、警方或收费运营方为准；社区内容只用于发现高频踩坑点。

当前发布版按覆盖度自然收敛为 166 道正式题（挪威 80、冰岛 86），另保留 43 道退役题的审计记录。题量不是发布目标：只有具备独立学习价值、两条不同官方来源且能明确核验的题目才会发布。

## 内容原则

- 每道发布题至少引用两个独立来源，并记录核验日期和适用日期。
- 罚款、通行费、停车费、租车公司手续费和保险除外责任分开表述。
- A 级图片为两国官方交通标志；B 级图片为许可和拍摄地明确的当地实景；C 级图片为官方出版物示意图。
- 不使用生成式图片、他国标志或地点不明的道路照片作为学习证据。
- 当前素材包含 104 张两国官方标志和 40 张许可、地点与原始文件哈希明确的当地实景；正式题中有 114 道图文题。
- `research/` 保存研究底稿与哈希清单，不随公开网页发布，但会作为单独研究档案交付。

## 本地验证

```bash
npm run test:content
npm test
npm run package:project
npm run package:research
```

`npm test` 会依次执行内容发布门槛、代码规范、TypeScript 类型检查、完整构建和服务端页面/PWA 元数据检查。

两个打包命令分别生成可复现的源码包和研究档案，并在压缩包旁生成 `.sha256` 校验文件。

## 数据目录

- `data/questions.json`：题目与答案。
- `data/sources.json`：来源与声明覆盖关系。
- `data/assets.json`：图片国家、许可、来源及本地离线路径。
- `data/manifest.json`：题库版本与发布门槛。
- `research/`：官方研究记录、社区线索、快照和素材证据。
- `source-archive/`：可直接保存的官方页面/PDF 快照；无法稳定抓取的页面以带哈希的研究证据记录代替。
